二 本任务目标

在现有 React + Vite 工程中制作高完成度、可操作的本地视觉原型和基础设计系统。使用模拟数据展示未来产品体验，但不接入服务端或真实游戏规则。

整体体验参考成熟斗地主产品的牌桌构图、手牌交互、状态提示和动画节奏，同时使用原创名称、布局细节、颜色、卡牌和图形，不复制腾讯商标、角色、图片、音频、字体文件或逐像素界面。

三 必须覆盖的原型

1. 首页
   - 品牌标题“永城八张”
   - 昵称输入
   - 创建房间
   - 房间短码加入
   - 规则与历史战绩入口
2. 创建房间界面
   - 自定义房间名
   - 二人、三人、四人模式
   - 20 秒倒计时
   - 允许观战和聊天选项
3. 等待房间
   - 房间名称、随机短码和复制邀请入口
   - 玩家座位、房主状态和开始按钮
   - 聊天区域或入口
4. 游戏牌桌
   - 自己和其他玩家座位
   - 手牌、牌墩、桌面牌
   - 主牌花色、当前攻守身份、行动者、倒计时、网络状态
   - 出牌、压牌、过、收牌、主 2 换明牌按钮的视觉状态
   - 合法牌、选中牌、不可用牌的不同状态
5. 结算界面
   - 获胜玩家或队伍
   - 再来一局和返回房间
6. 电脑端与手机横屏
   - 桌面参考尺寸：1440 × 900
   - 手机横屏参考尺寸：844 × 390

原型可以使用本地状态、页面切换按钮或开发预览导航来展示各场景，但不得调用后端业务接口。

四 设计系统要求

1. 在 `packages/ui` 或适合的共享位置建立可复用的视觉基础：
   - 颜色变量
   - 字体层级
   - 间距和圆角
   - 阴影和层级
   - 按钮状态
   - 面板、徽章、玩家座位和扑克牌基础组件
2. 视觉基调：现代在线牌桌、清晰、精致、有游戏氛围，不做简陋后台页面。
3. 可以使用墨绿牌桌、暖金或木色点缀，但最终方案由设计质量决定。
4. 红黑花色必须易辨认；不能只依赖颜色表达合法性或状态。
5. 动画应克制并支持 `prefers-reduced-motion`。
6. 保证键盘焦点、可读对比度、按钮可点击区域和基础语义结构。
7. 不从网络下载或复制商业游戏素材。若需要图形，优先使用 CSS、原创 SVG 或项目内原创资产。
