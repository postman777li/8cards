## 缺陷与修复

### T19-001 高：新观战者丢失加入前聊天历史

- 复现：玩家先发消息，观战者随后加入；服务端发送 `chat.history`，但观战页面为空。
- 根因：观战握手只保留响应、凭证和首个状态快照，忽略状态到达前的聊天历史；玩家恢复存在同类竞态。
- 修复：握手阶段缓存聊天历史并作为连接对象初始消息；恢复响应先发送聊天历史再发送身份状态。
- 回归：客户端握手单元测试验证 HTML 文本历史完整交付；Playwright 验证新观战者可见加入前消息且不会生成注入的 `img` DOM。
