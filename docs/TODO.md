# 永城八张完整任务路线图

本文是项目执行顺序的唯一任务清单。每个编号任务原则上对应一个独立聊天窗口。

## 使用方法

1. 只执行标记为“下一项”的任务。
2. 新窗口开始前，从最新 `main` 创建该任务指定的分支。
3. 新窗口只完成一个编号任务，不顺带开始下一项。
4. 完成后运行验收命令，更新本文和 `project-status.md`，并提交到任务分支。
5. 用户回到项目总控窗口，由总控检查、合并到 `main`，再宣布下一项。
6. 只有合并并推送到 `main` 后，任务才可以从 `[ ]` 改成 `[x]`。
