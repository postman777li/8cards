# 任务 22 精品体验审计与验收记录

## 编码前审计

- 首页已有品牌基调，但大面积留白与表单缺少材质层级；手机端第一屏品牌和主操作关系偏弱。
- 等待房座位、准备与换座功能完整，但多个矩形面板近似后台页面，四人对家关系缺少桌面氛围。
- 玩家牌桌只有牌墩数字、简单边框行动提示和通用三点动效；补牌去向、本人回合焦点、动作瞬态反馈不足。
- 聊天只有历史和输入框，快捷沟通、表情、未读后的轻量桌面反馈缺失。
- 观战是删减操作后的牌桌，缺少明确只读身份和可参与社交的完整体验。
- 单局结算和最终排名为文字列表；分差、倍率、投票、标准并列名次、奖牌与称号缺少视觉逻辑。
- 设置中的音效是占位开关，没有真实声音、音量或浏览器自动播放降级。

## 实现与原创来源

- 所有新增视觉均为项目内 CSS/React 原创实现；未下载第三方图片、字体、商标、角色、界面或音频。
- 音效由 `OscillatorNode` 与 `GainNode` 运行时合成，不产生外部音频资产；无背景音乐。
- 表情使用固定枚举与 CSS 几何图形，不允许任意图片 URL、HTML 或脚本。

## 性能与降级

- 动画只使用 transform/opacity，数量有界，不锁定权威状态或操作。
- `prefers-reduced-motion` 与本地“减弱动画”关闭位移动画；页面隐藏不播放音效。
- 音频节点创建失败、未解锁或系统禁用时静默降级；表情不保存历史，恢复不会批量重播。
