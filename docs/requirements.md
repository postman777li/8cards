# 第一版产品需求

## 用户与身份

- 玩家无需注册即可输入昵称进入。
- 使用浏览器访客身份支持断线重连。
- 需要保存历史战绩。
- 第一版战绩跟随当前浏览器中的访客身份；换设备或清除浏览器数据后，可以视为新的访客身份。

## 房间

- 玩家可以创建和加入私人房间。
- 房主负责开始游戏。
- 支持二人、三人和四人模式。
- 支持分享链接。
- 房间同时具有玩家自定义名称和系统自动生成的随机短码。
- 玩家既可通过随机短码加入，也可通过分享链接进入。
- 支持文字聊天。
- 支持观战，观战者不得收到玩家隐藏手牌。

## 游戏体验

- 支持电脑和手机浏览器。
- 默认操作倒计时为 20 秒。
- 进攻方超时自动过牌，防守方超时自动收牌。
- 玩家掉线后保留座位并允许重连。
- 进行中牌局掉线提供 3 分钟恢复宽限，普通回合倒计时继续；超时未恢复按主动退出判负并结束房间赛。
- 显示主牌、攻守身份、行动顺序、牌墩余量、玩家手牌数量和倒计时。
- 合法牌高亮，非法操作由服务器拒绝。
- 支持出牌、压牌、过牌、收牌和主 2 换明牌。
- 保存对局结果和关键事件记录。
- 支持同一房间原座位连续多局、权威积分/倍率、继续投票、完整出完排名和最终荣誉。
- 三人和四人等待房支持权威移至空座及经对方同意的座位交换。

## UI 方向

- 参考《欢乐斗地主》的牌桌布局、手牌交互、状态反馈和动画节奏。
- 使用原创名称、品牌、卡牌、美术、声音和字体资源。
- 不进行逐像素复刻。
- 视觉质量以可正式上线的游戏产品为目标，不接受简陋功能页。

## 第一版暂不承诺

- 公开匹配
- 排行榜和赛季
- 付费系统
- 好友系统
- 语音聊天
- 原生手机应用
